# 📊 Project 01 – Personal Budget Dashboard

## 📌 Project Overview
The Personal Budget Dashboard is an interactive Microsoft Excel dashboard designed to help users monitor their income, expenses, savings, and overall financial performance. It provides a clear visual summary of spending habits and supports better financial decision-making.

---

## 🎯 Objectives
- Track monthly income and expenses.
- Categorize spending for better financial analysis.
- Visualize financial performance using interactive charts.
- Calculate savings and remaining balance.
- Build a professional Excel dashboard using advanced Excel features.
