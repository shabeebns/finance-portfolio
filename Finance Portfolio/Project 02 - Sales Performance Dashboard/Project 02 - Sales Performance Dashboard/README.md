# 📈 Project 02 – Sales Performance Dashboard

## 📌 Project Overview

The Sales Performance Dashboard is an interactive Microsoft Excel dashboard developed to analyze sales performance across different products, regions, and sales representatives. It enables businesses to monitor key performance indicators and make data-driven decisions.

---

## 🎯 Objectives

- Analyze sales performance
- Compare regional sales
- Evaluate product performance
- Monitor monthly sales trends
- Build an interactive business dashboard

---

## 🛠️ Tools Used

- Microsoft Excel

---

- XLOOKUP
- SUMIFS
- COUNTIFS
- AVERAGEIFS
- IF Functions
- Conditional Formatting
- Data Validation
- Dashboard Design
