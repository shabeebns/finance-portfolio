# 📊 Project 01 – Personal Budget Dashboard

## 📌 Project Overview

The Personal Budget Dashboard is an interactive Microsoft Excel project designed to help individuals monitor their income, expenses, and savings. The dashboard transforms raw financial data into meaningful insights, making it easier to track spending habits and improve financial planning.

---

## 🎯 Objectives

- Track monthly income and expenses
- Monitor savings and remaining balance
- Analyze spending by category
- Present financial data through an interactive dashboard

---

## 🛠️ Tools Used

- Microsoft Excel

---

## 📚 Excel Skills Demonstrated

- XLOOKUP
- SUMIFS
- COUNTIFS
- AVERAGEIFS
- IF Functions
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- Data Validation
- Dashboard Design
